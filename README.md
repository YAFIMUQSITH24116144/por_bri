# Neo-Brutalist Interactive Board Portfolio Template ($1 Tier)

An experimental, high-impact portfolio template built with **HTML5**, **Tailwind CSS**, and **Vanilla JavaScript**. Features hard shadows, vibrant neon colors, draggable moodboard elements, and raw brutalist aesthetics.

---

## ⚡ Key Features

- **Draggable Board Cards:** Users can click & drag elements freely around the canvas screen.
- **Neo-Brutalist Aesthetic:** Thick 3px/4px borders, hard black offsets, high contrast neon colors.
- **Marquee Announcement Banner:** Infinite scrolling status header.
- **System Live Clock:** Live digital time display.
- **Interactive Inspection Modal:** Custom popups with sharp brutalist drop shadows.

---

## 🛠️ Quick Customization

1. Open `index.html` to update text content, colors (e.g., `#FFE600`, `#FF2E93`, `#00FF66`), and project listings.
2. Edit `assets/js/main.js` to change the destination email address in `copyEmail()` function.
