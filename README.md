# ⚡ Neo-Brutalist Interactive Portfolio Template

> **Plug-and-Play Portfolio for Designers, Developers & Creative Directors.**
> Stand out with a high-impact, interactive board layout. Zero build tools required — just open, edit the HTML, and host for in minutes.


## 🚀 Why You'll Love This Template

- **Pure Vanilla JS Drag Engine:** 
Fully interactive drag-and-drop canvas with zero heavy frameworks or external npm packages.
- **Metric-Driven Case Studies:** 
Built-in layout to showcase real business results (example *66M+ Downloads*, *+140% Conversion Lift*).
- **Mentorship & Services Bento:**
 Dedicated blocks for 1-on-1 coaching, product audits, and design sprints.
- **Dynamic Inspection Modal:** 
Popup windows triggered with dynamic parameters (images, metrics, descriptions).
- **Plug & Play Styling:** 
Powered by Tailwind CSS CDN for instant customization without compiling CSS.


## 🛠️ Quick Setup (3 Easy Steps)

1. **Change Your Info (`index.html`)**
   - Open `index.html` in VS Code or any text editor.
   - Replace the text, image URLs, and metrics with your own details.

2. **Set Up Project Modals (`index.html`)**
   - Update the parameters inside `openBrutalistModal()` directly in your HTML tags:
     ```html
     onclick="openBrutalistModal('PROJECT TITLE', 'DESCRIPTION', 'IMAGE_URL', 'METRICS #1', 'METRICS #2')"
     ```

3. **Update Your Email (`assets/js/main.js`)**
   - Change `const email = 'your-email@domain.com';` so the "Copy Email" button works for you.

## 📦 Zero-Config Deployment

Since this is a static site (HTML/CSS/JS), you can deploy it for free instantly:
- **Vercel / Netlify:** Drag & drop the template folder directly onto your dashboard.
- **GitHub Pages:** Upload files to a repo and turn on Pages in settings.
